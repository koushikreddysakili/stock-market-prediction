About This Project

This project predicts the next day's stock closing price using a Machine Learning model.

Project Objective

To help users estimate future stock prices by analyzing historical stock market data.

Machine Learning Algorithm

Random Forest Regressor

Dataset Features

  • Previous Close Price
  • Open Price
  • High Price
  • Low Price
  • Closing Price
  • Trading Volume
  • Moving Averages
  • Daily Returns
  • Price Volatility
